1.Architecture comparison (272-dim HumanML3D)

The published MoLingo baseline does not use SRM. We add an SRM-based rectified-flow backbone, then compare two variants on top of it: one with RoPE attention (SRM+RoPE), one with per-layer AdaLN conditioning (SRM+AdaLN).

SRM+RoPE has the lower FID. SRM+AdaLN has the better text-motion alignment and matching score.

2.Kimodo (273-dim representation)

We adopted Kimodo's 273-dim representation mainly for its downstream applications. It is built to retarget onto real robot skeletons, like the Unitree G1, for physical deployment, something the standard HumanML3D representation does not support. It also adds foot-contact and canonical-joint information that the 272-dim representation lacks, which later turned out to help with the scene and object grounding in Section 4.

Kimodo's own reference model is a discrete diffusion model with no latent space. We built our own VAE and a continuous-latent diffusion model on top instead, following the same design as Section 1.

We re-tested SRM+RoPE against SRM+AdaLN on this new data before committing to one. SRM+AdaLN showed less jitter and trained more stably, so it is the architecture behind the Kimodo VAE, diffusion model, and ControlNet below.

This ControlNet brings Kimodo-style control, such as following a root trajectory or matching a few keyframes, to our own VAE-latent model. In each clip below, the control signal comes from one motion, but the text prompt asks for a different action.

4.Scene-aware and object interaction

This is the current phase. It extends the same ControlNet with a scene encoder and an object encoder, so the model can navigate a scene and interact with objects, such as reaching for or sitting on them. It is trained on TRUMANS data.
